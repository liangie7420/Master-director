# Master director

> **100% 原创** 的 AI 漫剧 / 短剧导演技能：把一段原文或主题，转化为可投喂视频模型逐镜头产出的整套生产管线。

适配视频模型：**Seedance 即梦 / 可灵 Kling / 海螺 Hailuo**

---

## 🎯 项目定位

manju-director 是一套**从剧本到成片的完整导演工作流**，不是单个镜头的提示词工具。它把传统影视导演的"分镜-定妆-一致性-质检"工序，全部翻译成视频模型可执行的生产文档，让 AI 逐镜头产出连贯、一致、少抽卡的漫剧成片。

**适用场景**：AI 漫剧 / 动态漫 / 短剧批量生产；任何想把"一段原文或一个主题"变成"一整集可投喂视频模型的逐镜生产包"的需求。

## 🔑 三大一致性机制（核心创新）

| 机制 | 解决什么 | 做法 |
|---|---|---|
| **尾帧承接** | 镜头间画面连贯 | 上镜成片尾帧（`extract_last_frame.py` 提取）作为下一镜首帧，画面无缝延续 |
| **资产卡锁定** | 人物/场景一致，防串脸漂移 | 角色卡/场景卡/道具卡 + 定妆图冻结，提示词锚点逐字复述 |
| **关键帧插入** | 新角色/新道具安全登场 | 新元素首次出现先产定妆定场帧，再进叙事镜头 |

## 🎬 工作流一览（阶段 0 → 6）

```
立项（题材/模型/画幅/画风）
  → 剧本工程（标准分镜剧本，动作表情写到指尖与眼神）
  → 资产卡与定妆（项目档案/角色卡/场景卡/复合资产图，闸2 冻结）
  → 对话关系板 + 分镜表（闸3，6 格锁轴线）
  → 逐镜提示词（首帧图 + 视频提示词，闸4 首镜确认）
  → 拍摄执行与尾帧衔接（逐镜循环，翻车矩阵 + 双寄存器决策）
  → 质检与抽卡控制（一致性核对 + 连刷上限 3 次降级）
```

## ✨ 为什么少抽卡（工程纪律）

- **R1 细节密度**：动作表情写到部位级（指尖/喉结/呼吸/衣料）
- **R3 一镜一主动作**：防肢体崩坏第一原则
- **R4 锚点逐字复述**：外观锚点不改写，防漂移
- **R5 资产收敛链单向**：色卡→定妆→分镜→提示词→成片→尾帧，下游永远引用上游已冻结产物
- **五道确认门**：每阶段产出交用户确认，减少批量返工

## 🛠 快速开始

1. 将本项目放入 WorkBuddy 技能的 `~/.workbuddy/skills/` 目录（或解压 `manju-director.zip` 后放入）
2. 对话中提及"漫剧/短剧剧本/分镜脚本/逐镜提示词/尾帧衔接/角色一致性"等关键词即可触发
3. 尾帧提取脚本依赖 ffmpeg：安装后加入 PATH，或设置 `FFMPEG_BIN` / `FFPROBE_BIN` 环境变量
   ```bash
   python scripts/extract_last_frame.py input.mp4 -o frames --shot 1
   ```
