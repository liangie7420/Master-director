# 项目档案｜关门前的来信

## 已写入示例的设计决定

- 题材：都市情绪短片。
- 时长与画幅：60 秒，16:9。
- 画风：二维动画，清晰深色线稿，克制的色块阴影。
- 色彩逻辑：店内暖白、街外冷蓝；结尾柜台台灯增加一处暖黄。
- 核心叙事：从“替明天作出最终决定”转为“给自己保留一天”。
- 画面母题：营业牌的两次翻转；始终可辨认的蓝绳铜钥匙。
- 声音策略：后期配音与音效。提示词中的表演和画面仍需与后期录音对齐。
- 文字策略：纸面和牌面由图像模型留白，清晰汉字后期合成。
- 默认准备配置：seedance-2.0-ark，仅用于本地编译示例；没有视频 API 调用。
- 创作确认：illustrative_only。这些是演示决定，不是用户真实剧集已通过的确认门。

## 连续性

柜台、门窗保持世界空间位置。对话机位保持在同一侧，反打按实际位置设计视线。拆封、走到门边等非核心动作可以通过明确的时间省略切镜。

S01–S09 的店内基础光一致；S10 台灯亮起是有原因的变化。不能把“复制光源句”当作真实输出已经一致的证据。

每镜的图生视频首帧均单独设计；角色/场景参考不自动充当所有镜头首帧。

## 验收

观众能读懂两次营业牌动作、信封交接、钥匙落掌和结尾点灯。角色与道具保持可辨认的设计；文字与声音在后期可读、可听且与表演同步。实际通过情况写入 review.json。
