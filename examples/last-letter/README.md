# 《关门前的来信》｜60 秒完整生产准备示例

这个示例展示从故事到可交给图像/视频平台的生产材料。它是原创演示，不代表已经生成或验收的成片。

- 画风：二维都市动画。
- 规格：16:9，10 镜 × 6 秒，总计 60 秒。
- 角色：顾宁、林川；一个主要书店场景。
- 声音：后期配音与音效；牌面、信中文字后期合成。
- 生成状态：图片、视频与视觉评分均为 not_run。

## 顺序阅读

1. [源故事](story.md)：输入是什么。
2. [项目档案](episode-bible.md)：人物、画风和交付决定。
3. [资产卡](cards/CH-01.md)：角色与设计如何保存；同目录含两张角色卡、场景卡和三张道具卡。
4. [完整剧本](script.md)与[分镜验收表](shotlist.md)：每镜为什么拍、怎样拍、验收看什么。
5. [镜头 JSON](shots/S01.json)：可编辑的确定性输入。
6. [首帧提示词](prompts/S01-first-frame.txt)与[视频提示词](prompts/S01-video.txt)：逐镜输入示例；prompts/ 含全部 20 份文本。
7. [平台操作与回填](platform-handoff.md)：补真实素材、生成、剪辑和记录结果。

## 一条命令准备独立工作副本

在源码目录运行，输出到一个新的目录：

```bash
python scripts/prepare_example.py --out demo-output
```

已安装技能时，从技能的实际目录调用该脚本，把 --out 指向你的创作目录。工具复制内置故事并编译对应输入，不调用语言、图像或视频模型。

产物包括所有设计文件、20 份提示词、20 份准备报告、review.json 和 production-status.json。
全部首帧和参考图路径都是待提供素材，视频输入以草稿状态保留，不应直接当作已完成上传的请求。

将示例换成自己的故事时，用宿主 AI 按技能重新创作；这个固定示例命令不会自动改编任意输入故事。
