# Kling Adapter

Audit: 2026-10-17. Exact model version and web/API entry must be selected before using numerical capability limits.

The previous combined table for 1.6/2.0/2.1 is retired: first/last-frame, references, audio, editing and duration cannot be inferred from the family name.

## Current local support

The kling-configure-version profile allows a review draft. It intentionally has no asserted model ID, task limits or audio support.
The official developer site blocked automated retrieval during this audit. The provider's 3.0 announcement documents newer multimodal/video-editing and native-audio capabilities, so the old family-wide “no audio” table is invalid. Fill exact model/entry parameters before strict preparation; do not transfer series-level claims into unsupported API fields.

## Direction that remains useful

Bind each subject to its real reference. Distinguish identity from a first-frame role.
Describe the intended motion, spatial relation, camera and landing in concrete terms. Motion amplitude follows the scene; “slow” is not a universal default.
Native sound, negative fields, duration, start/end frames and camera controls are version-specific configuration, not mandatory paragraphs.
