# 玄幻题材执导手册

> 适用：东方玄幻 / 仙侠 / 修真 / 妖魔等题材短剧 | 全文原创，无版权风险
> 配套：场景卡配色铁律从本章取词；特效"颜色=阵营"双区分轴设计见第 2.4 节。

## 1. 题材调性与情绪曲线范式

### 1.1 核心爽点引擎
- **扮猪吃虎**：弱者伪装，强者打脸（观众与主角共享信息差，反派不知道）。
- **境界碾压**：等级体系清晰（练气→筑基→金丹…），碾压时的视觉落差。
- **夺宝/奇遇**：神秘物件登场 = 命运齿轮（关键帧插入的高频触发点）。
- **渡劫/破境**：天象异动，全场景高光（科幻片没有的天然大场面）。
- **身份揭晓**：凡人身世 = 上古血脉/转世，反转观众的"已知"。

### 1.2 90 秒单集情绪曲线模板（四拍）
| 时间窗 | 阶段 | 给观众什么 |
|---|---|---|
| 0–15s | 羞辱/困境 | 主角被压制（境界差/身份差），钩子=憋屈 |
| 15–45s | 暗手/底牌 | 主角亮出超出境界的手段（一次小爽点） |
| 45–75s | 破局/反转 | 关键道具或身份浮出，局势翻转（高能点） |
| 75–90s | 碾压+新悬念 | 打脸完成 + 更大敌手/更高境界登场 |

### 1.3 多集连播曲线
每集一个"憋屈→翻盘"闭环，结尾开新坑（新仇人/新秘境/新境界）；爽点密度是生命线，**每 15 秒至少一次小爽，每集至少一次大爽**。

### 2.4 特效"颜色=阵营"双区分轴（防特效串色的命门）
- 轴 1 颜色：主角灵力争**青/翠**（#7FD4C1 系），反派魔气争**赤/紫**（#E0472E 系），锁死 HEX，全片不换。
- 轴 2 形态：同色系也不许同形态——主角=粒子流，反派=墨雾状；配角=光晕状。
- 负向常驻：`禁止主角使用红色特效，禁止反派使用青色特效`。

## 3. 镜头语言偏好

### 3.1 高频镜头对照表
| 情境 | 推荐景别/运镜/焦段 |
|---|---|
| 境界威压 | 仰拍大特写（眼/下颌）+ 极缓推 |
| 御剑飞行 | 大远景 + 侧跟 + 广角 |
| 法器/丹药展示 | 大特写 + 极缓推 + 85mm |
| 掐诀施法 | 手部特写 + 固定 + 微距感 |
| 法术对轰 | 中景双人 + 固定/微移（一次一个主动作） |
| 渡劫天象 | 大远景 + 缓升 + 广角 |
| 市井日常 | 中景 + 手持微晃 + 50mm |

### 3.2 武戏/法术对轰安全写法
- **一次只压一个主动作**：同一镜里"挥剑"和"闪避"必须拆开（R3）。
- 法术对轰用"接触点"代替"光球飞行的全过程"：写"两道光在画面中央相撞，冲击波扩散"比写"光球飞行轨迹"稳。
- 肢体动作：剑指/持剑手型是关键命门，手部镜头一律固定机位+慢速。
- 长发与衣袂：写"发丝/衣摆随动作滞后半拍"制造真实惯性，防止穿模悬浮。

### 3.3 节奏控制
- 文戏 6–8s/镜；斗法 4–6s/镜；施法特写 4–5s/镜；天象大场面 8–10s/镜。
- 施法动作四拍：抬手→掐诀→蓄力（灵力汇聚）→释放，每拍 1s 左右。

## 4. 表演与台词风格

### 4.1 动作/微表情描写句式（可直接复用）
1. 掐诀：`五指先并拢，中指与拇指相扣，指尖沁出一线流光`。
2. 拂袖：`广袖一拂，袖风卷起案上香灰，声音不大，气场压人`。
3. 威压下的生理反应：`他额角渗出薄汗，膝弯微颤，下颌绷紧却不肯低头`。
4. 受伤：`她以手背拭去嘴角血线，指节蹭过唇角时眉头几不可察地皱了一下`。
5. 破境瞬间：`闭目，睫毛轻颤，再睁眼时瞳中精光一闪而逝`。
6. 妖性/魔性显现：`瞳孔在暗处缩成一线，唇角弧度慢慢扬起，笑意不达眼底`。
7. 强者姿态：`他负手而立，从头到尾没动过脚步，只有衣摆无风自动`。

### 4.2 台词风格（各附原创例句）
- 古风语感：称谓 + 短句 + 留白——"阁下此来，是为叙旧，还是为取我的命？"
- 狠话/底线："我敬你是前辈，才容你三次。第四次，我不讲道理。"
- 身份揭晓式："你当真以为，当年那个灭门的孤儿……是个凡人？"

## 6. 题材级翻车点与负向约束

| 翻车 | 负向写法（中英对照） |
|---|---|
| 古装=影楼风 | 不要影楼摄影棚感 avoid studio portrait look |
| 法术糊成光污染 | 不要过度光效不要光污染 avoid excessive glow |
| 长发飘动穿模 | 不要头发穿入身体 avoid hair clipping |
| 结印手指崩坏 | 不要手指变形 do not deform fingers |
| 特效串色（正反派不分） | 禁止主角特效使用红色 avoid red effects on protagonist |
| 仙侠=网游渲染 | 不要游戏渲染质感 avoid video-game render |

## 7. 视频模型适配要点

- **Seedance**：灵气粒子/流光类特效表现强；写清特效颜色与形态（双区分轴）。
- **可灵**：古装服饰动态（绸缎/长发）粘性较好；武戏幅度默认低。
- **海螺**：水墨/仙气风格化适配度高；6s 档适合"施法四拍"完整闭环。
