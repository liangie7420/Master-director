# 言情题材执导手册

> 适用：甜宠 / 虐恋 / 暧昧拉扯 / 先婚后爱等言情短剧 | 全文原创，无版权风险
> 配套：双人"距离管理学"与暧昧戏的安全边界写法见第 3.3、3.4 节。

## 1. 题材调性与情绪曲线范式

### 1.1 核心情绪引擎
- **暧昧蓄力→试探拉锯→权力翻转→收束**：言情短剧的四拍引擎，本质是"关系权力"的拉锯战。
- **甜点**：关系推进的瞬间（确认心意/守护/回头）。
- **虐点**：关系后退的瞬间（误会/分离/牺牲），虐点是甜点的放大器。
- **配比**：甜虐比建议 7:3（短剧市场甜宠为主）；虐点一次不超过 15 秒，立刻给甜点回血。

### 1.2 90 秒单集情绪曲线模板（四拍）
| 时间窗 | 阶段 | 给观众什么 |
|---|---|---|
| 0–10s | 触点 | 一次近距离接触/一个眼神/一句带刺的话 → 钩子 |
| 10–45s | 试探 | 双人拉锯，每 8–15s 一个关系推进事件（近一步/退一步） |
| 45–70s | 爬坡 | 暧昧到达峰值（靠近-停顿-未完成的动作），钩子=悬而未决 |
| 70–90s | 翻转/收束 | 一次小确认或新误会（二选一，别贪多） |

### 1.3 暧昧爬坡阶梯法
每 8–15 秒一个"距离事件"，按物理距离递进：同框对视 → 越肩 → 半臂距离 → 一拳距离 → 呼吸可闻。**每个事件都要"未完成"**（快碰到又收手、话到嘴边又咽下）——未完成才是暧昧。

## 3. 镜头语言偏好

### 3.1 高频镜头对照表
| 情境 | 推荐景别/运镜/焦段 |
|---|---|
| 暧昧逼近 | 大特写双人 + 极缓推 + 85mm |
| 心动瞬间 | 浅景深近景 + 固定 + 85mm，环境虚化 |
| 试探对视 | 正反打特写交替 + 固定 |
| 分离 | 大远景 + 固定长镜 8–10s |
| 守护/回头 | 中景 + 缓拉 + 50mm |
| 信物/定情物 | 大特写 + 极缓推（关键帧插入点） |
| 未完成动作 | 特写（手/脸）+ 固定，定格 1s 再收 |

### 3.2 双人距离管理学（镜头语言化）
- **距离 1 同框**：中景双人同框，两人之间有 1–2 人身位 → 关系安全区。
- **距离 2 越肩**：A 越 B 肩，B 面部受 A 遮挡一角 → 关系走近。
- **距离 3 双人大特写**：两人同框大特写，面颊相距不及一拳 → 暧昧峰值。
- **距离 4 局部交替**：手/唇/眼的局部特写交替 → 张力最大（未接触但比接触更勾人）。
- 退阶同理：从双人大特写退回越肩 = 关系降温，剧本里"退半步"要在镜头里体现。

### 3.3 亲密戏安全边界（平台审核+模型能力内）
- 用"未完成动作"表达亲密：靠近-悬停-收手；贴唇-错开；呼吸相交-后退。
- 借位：前景遮挡（纱幔/肩部/道具）代替直接接触。
- 意象化：烛火/雨水/花瓣代替身体接触。
- 明确边界：接触戏到"脸颊相贴/额头相抵/拥抱"为止，其余留给留白。
- 提示词写法：写"二人面颊相距不及一拳，呼吸相交，未接触"，不写接触动作本身。

### 3.4 节奏控制
- 暧昧戏单镜 6–10s（情绪特写给足时间）；对话 6–8s；分别长镜 8–10s。
- "情感过载型沉默"：每场暧昧戏至少 1 个 3–4s 的沉默镜（只拍呼吸与微表情），这是言情戏的标点符号。

## 4. 表演与台词风格

### 4.1 动作/微表情描写句式（可直接复用）
1. 喉结：`他喉结滚了一下，目光从她唇上移开，落在别处`。
2. 指尖悬停：`她的指尖悬在他袖口上方，停了半秒，又轻轻收回`。
3. 垂眸：`她垂眸，睫毛在眼下投出一小片阴影，再抬眼时，笑意已收`。
4. 气声：`她说话几乎是气声，尾音很轻，像怕惊动什么`。
5. 耳坠/发丝：`她侧过头时，耳坠晃了晃，一缕碎发从耳后滑落`。
6. 呼吸变化：`他呼吸重了一拍，随即压下，喉间那口浊气半天没咽下去`。
7. 抢话/停顿：`她说完立刻咬住下唇，像后悔说得太快——却又不肯收回`。
8. 欲言又止：`他张了张嘴，最终还是把话咽回去，只点了点头`。

### 4.2 台词风格（各附原创例句）
- 气声/留白："……别动。"（停顿）"你头发上，有片叶子。"
- 试探双关："我请你吃饭，是看在同事三年的份上。"（潜台词：不然呢？）
- 口是心非："谁等你了？我刚好路过。"（却站在原地没走）
- 狠话带钩子："从今天起，我们两清。"（说完却站着不动）
- 沉默的戏：台词越少越有戏，一句"嗯"配三秒微表情，胜过十句解释。

## 6. 题材级翻车点与负向约束

| 翻车 | 负向写法（中英对照） |
|---|---|
| 双人同框串脸/五官互染 | 不要两人面部融合 do not merge faces |
| 手部接触穿模 | 不要手指穿入身体 do not clip fingers |
| 皮肤塑料感 | 不要塑料皮肤 avoid plastic skin |
| 发丝与衣物粘连 | 不要头发与衣服粘连 avoid hair stuck to clothes |
| 暧昧戏表情僵硬 | 不要僵硬表情 avoid stiff expression |
| 亲密接触过度（平台风险） | 保持距离感，二人未接触 keep distance, no physical contact |

## 7. 视频模型适配要点

- **Seedance**：面部特写与微表情是强项，暧昧大特写出片率高；气声台词口型弱，建议后期配音。
- **可灵**：双人同框易串脸——严格用定妆双图+减少同框时长，正反打拆开。
- **海螺**：情绪序列（先错愕后收敛）表现好；6s 档适合"未完成动作"的单拍闭环。
