# Dialogue Relationship Board / 对话关系板 DB-##

Use a board when multiple subjects, camera reverses or spatially difficult interaction make it useful. Simple conversation can be planned directly in the shot specification.

Choose a grid/cell count that presents the required cameras clearly; 2×3 is an optional contact-sheet layout, not a limit on conversation length.
A sheet's left column is a page layout, not a universal subject screen position.

## Generation
Bind each reference to a character. Describe the medium and actual required camera states.
Keep lighting/costume/time coherent across cells representing the same moment.
Use medium-compatible constraints. Animation boards must not inherit generic exclusions of anime/cartoon.
For tool use, actual image size and uploads are parameters; text labels alone do not set them.

## Review actual output
- Identity and costume match for each visible character.
- Screen direction, gaze target and foreground shoulder ownership match the selected camera.
- Required space/contact remains legible.
- Cell layout matches the designed board if a grid was requested.
- Mark approved cells and their real files before using them as shot references.
