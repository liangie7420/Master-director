## Asset creation
Choose a view, pose, background and light that make the distinguishing features inspectable.
Text-only generation is allowed for a new identity. If preserving an existing identity, bind the actual reference.
Neutral or scene-specific light, deep or shallow focus, full/half body and profile views are chosen for the asset's job. Do not select lighting by gender.
